### Клиент без дополнительной установки 

Клиентская часть — **только HTML, CSS и JavaScript** в браузере. Не требуются Node.js, npm, React, сборщики или плагины.

Для работы интерфейса достаточно:

1. Запустить сервер Python (`python3 app.py`).
2. Открыть **http://127.0.0.1:5000** в обычном браузере.

### Полная история изменений 

Данные **не удаляются физически** из SQLite:

| Действие в интерфейсе | Что происходит в БД |
|------------------------|---------------------|
| **Удаление** | `is_active = 0`, снимок в `*_history` с операцией `DELETE` |
| **Изменение** | Снимок старой версии в `*_history` с операцией `UPDATE` |
| **Создание** | Запись в `*_history` с операцией `INSERT` |

**Защита связанных данных:** если на отдел ссылаются проекты (`projects.department_id`), при редактировании отдела старая запись **архивируется** (`is_active = 0`), создаётся **новая** активная запись с новым id. Проекты продолжают ссылаться на старый id и отображают **прежние** данные отдела (подпись «(архив)» в таблице проектов).

Таблицы истории: `departments_history`, `projects_history`. Просмотр — кнопка **«История»** у выбранной записи.

При обновлении БД с шага 2 при старте приложения выполняется автоматическая **миграция** (`migrate_db` в `app.py`).
